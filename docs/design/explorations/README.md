## Preferences already received

- Watercolor-and-ink kitten: first favorite.
- Layered-paper kitten: second favorite.
- The selected luminous variants remain useful, especially for continuity with the app's own character.
- The extra first luminous sheet is outside the active set; original generated source files have not been deleted.
- No dogs; keep the cast black. Explore long and slender, round, and baby-kitten builds, distinct eye colors, and possibly differently colored eyes and glowing accents for one cat. Exact character assignments remain open.
- Main postcard scenes use composed encounters and distinct actions rather than repeating a contact-sheet pose.
- Mixed-media cohesion is the concept under study. Comic panels, superhero styling, halftone effects, and a copied fictional universe are not the direction.
- Shared discovery is the narrative lead: curious peers exploring together, including the main character. Tie the emotional beats to actual user tasks in Gatto, without requiring screenshots.
- Physical contact is appealing, but the current scenes have reported anatomy and continuity problems. They remain unresolved reference material. Establish each individual's proportions and identifying traits before composing more encounters.
- The postcard feedback favors Coconat's cute lettering and the practical promise. Character design is the next priority; the current overall effect feels too babyish. Preserve the favored material detail while comparing less exaggerated proportions. Basteleur is a likely readability concern, pending confirmation of the specimen referred to as “by the way.”

These are working preferences from the conversation, not approval of a full site or final cast.

## Opening and answering

Open `index.html` in a browser with this folder and its `art/` subfolder intact. New studies embed their fonts and load artwork from local files, so no internet or server is required. The larger original mood board and system study embed their artwork as well. External source links require the internet.

Each interactive study has **Copy my responses as Markdown**. The taste interview exports its whole current two-round conversation in one click. Download is an alternative. If browser security prevents automatic copying, the same button opens and selects the Markdown for manual copying. Partial answers are exportable; unanswered and uncertain choices are identified.

Drafts are stored only in the browser where storage is available. File-based storage differs between browsers, so copy or download before relying on it. Nothing is submitted, synchronized, or sent to another service. A URL containing `?qa=1` uses a separate testing draft, so validation does not prefill the user's interview.

The substantially redrawn studies export version 0.3 with artwork revision `redraw-2`. Responses to earlier artwork are retained in the export under an archived section; current questions start separately so earlier reactions are not mistaken for responses to the redraw.

The interview's second round depends on settled first-round preferences. An uncertain answer is not silently resolved. Changing an earlier choice hides and invalidates old follow-ups; their stale answers are excluded from the export. The questionnaire is unscored and has no diagnostic or psychometric claim. Recommendations are optional starting hypotheses, tucked behind disclosure controls to avoid preselecting taste.

## Verification for this exploration

Check embedded script syntax, local links and artwork paths, readable narrow layouts, the conditional question tree, export content, copy fallback, and reduced-motion behavior. Passing selected contrast pairs is not a complete accessibility audit. These local studies do not measure or promise a production site's loading performance.
